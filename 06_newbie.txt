1. 시작할 때 (최신 상태 맞추기)

git checkout [브랜치명] : 작업할 브랜치로 이동 (예: git check out jys/dev)
git pull origin [브랜치명] : 서버의 최신 코드를 내 컴퓨터로 가져오기 (예: git pull origin main) 메인에 있는 코드를 내 컴퓨터로 가져옴.

2. 에러 발생 시 (강제 초기화) -- 가능하면 쓰지말자.

git reset --hard HEAD : 내 로컬의 변경 사항을 모두 버리고 마지막 커밋 상태로 복구 -- 파일 다 날아갈수도있으니까 주의주의.
git clean -fdx : Git이 관리하지 않는 파일과 .gitignore에 등록된 무시된 폴더까지 강제 삭제

3. 작업 완료 후 (저장 및 업로드)

git add . : 변경된 모든 파일을 올릴 준비
git commit -m "작업내용" : 내 컴퓨터에 저장 (메모 남기기)
git push origin [브랜치명] : 서버(GitHub)에 내 작업물 업로드

4. 기타 확인

git status : 현재 어떤 파일이 수정되었는지, 브랜치 상태는 어떤지 확인
git branch : 내가 지금 어떤 브랜치에 있는지 확인
