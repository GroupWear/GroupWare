<h2 세팅>
1. http://localhost:8080/Groupware/h2-console
2. 초기 1회 데이터베이스 생성 필요
3. cmd를 열고 type NUL > C:\Users\user\groupware_db.mv.db를 입력해 db 생성 // 개인 환경에서는 경로명 변경 필요
4. dir C:\Users\user\groupware_db.mv.db를 입력해 db 생성 확인 또는 직접 찾아가서 확인
5. jdbc:h2:~/groupware_db;MODE=Oracle;AUTO_SERVER=TRUE이 제대로 입력되었는지 확인하고 로그인
